## 1. Overview
- Wizards of the Coast's Magic: The Gathering, 1v1 against an AI, plain browser JS with no build step, one `window.MF` namespace, 20 life (40 in Commander), London mulligan. A **reproduction**: "fidelity is the product", Wizards owns rules and balance, Oracle text is on the face verbatim, and a card the compiler cannot read in full is refused from every deck (`CLAUDE.md` regime). Engine surface `legalActions / apply / isTerminal / whoActs`; one door each for ask, cost, damage, zone move and characteristics (layers, CR 613); cards are compiled from Oracle text by a grammar (`tools/build-cards.mjs`), checked by `tools/audit-cards.mjs`.
- State at 2026-11-01: 20 decks from two Standard eras plus two Bloomburrow Starter Kit decks, Kujo's Commander list, five championship cEDH lists; 535 cards audited, 581 of 581 illustrated, 454 tests.
- Owner decisions (do not re-ask): **D1/D2 2026-10-03** private and local, named MANAFORGE (neither "Magic" nor bare "Forge"); **D12 2026-10-03** supersedes D1, public repo and Pages for web playtesting, the concern (the policy does not cover a rules-enforcing client) stated once beforehand; **D15 2026-10-05** decks from two Standard eras only, "limited, last 2 trilogies" (read as Final Fantasy and Hobbit eras), 10 archetypes each, from Pro Tour Final Fantasy results and Wizards' weekly Arena Traditional Standard lists; **D16** Final Fantasy and Hobbit characters are painted despite the second rights holder; **D19 2026-10-25** "great job doing the interfaces for grand line and lorecannae, do manaforge next"; **D20 2026-10-27** "give these games the hearthstone treatment on mobile. ## 4. Lessons for the series
- *(added 2026-11-01, MANAFORGE)* **An engine-only fuzzer can't see the crashes players hit.** Recorded in [gotchas.md](gotchas.md) (2026-11-01: 549 random engine games, 311k actions, clean; 24k decision states drawn in the real page found three crashes first round). The sweep tools are on the unmerged branch named in the header. Save and continue (PLAN D26, 2026-11-02) is [rules.md](rules.md) rule 22; not repeated here.
- *(added 2026-11-01, MANAFORGE)* **A/B a new AI heuristic before keeping it, and commit the negative result.** The Commander mulligan sounded right (fast mana counted as lands) and played worse; it was turned off behind a named weight rather than deleted, so the test and the A/B can be rerun (`f4e33f1`, `974f9d6`).
- *(added 2026-11-01, MANAFORGE)* **A cost-order fix can open a new double-spend; reverse the cast, don't crash.** Paying mana before additional costs (CR 601.2g-h, `1d83e7e`) let the mana payment use a Treasure that an additional cost had already chosen; the Commander arena found the crash and `082e846` reverses the cast under CR 733.
- *(added 2026-10-31, MANAFORGE)* **A comment placed mid-line in a regex line silently dropped three conditions.** "to an opponent", "to a player" and "combat" vanished from every deals-damage trigger for hours; it was caught before reaching `main` and two regression tests now fail on that line (`6317275`). Run the suite after any edit to a compiler or matcher line, including comments.
- *(added 2026-10-31, MANAFORGE)* **Quadratic scans read the layers once.** An AI attack decision on a 36-permanent board took 8.5 s because each permanent triggered its own layer pass; reading `MF.charsAll` once per scan made it 1.1 s (`6317275`). Cap roll-outs per question too: a 155-pair block once took 37 s, now 12 answers at most. Still up to about 4.5 s on 35-50 permanents (`TODO.md`).
- *(added 2026-10-31, MANAFORGE)* **A static's value must read the table the door passes, never the door.** Gornog's +X/+0 per Coward called `MF.chars` from inside the layer computation and recursed forever; an AI-vs-AI game found it (`ceeb2d2`). The same game-found-it pattern caught the Crop Rotation cost order.
- *(added 2026-10-31, MANAFORGE)* **Hosted image rendering can replace a missing GPU, once the model and seeds are identical.** D23 reran the same SDXL base 1.0 prompts, seeds, size and negative prompt through Hugging Face's router (fal-ai provider); `hf-inference` no longer served SDXL (HTTP 410). 238 images, 0 failures, 3 re-rolled after a contact sheet. The router bills the owner per image.
- *(added 2026-10-31, MANAFORGE)* **Pull a deck list from event standings, not from a name.** `tools/fetch-cedh.mjs` took the best-placed list of each commander from the top 16 of the 16 largest 2026 events on EDHTop16 and kept event, standing, record, player and source URL beside each list; five commanders were chosen to minimise the cards the compiler could not yet read (120).
- *(added 2026-10-05, MANAFORGE)* **When an owner's word names two things, say which reading you took.** "Limited" in Magic means draft and sealed, so PLAN D15 records it was read as "the two eras"; likewise the Hobbit era had no championship Standard event, so Wizards' weekly Arena lists were clustered into archetypes instead (`tools/fetch-championship.mjs`, 283 lists).
- *(added 2026-10-05, MANAFORGE)* **Escape every attribute the HTML inserts, including the apostrophe.** Escaping missed `'`, so a button whose label held "Oracle's Gift" did nothing; `tools/check-pages.mjs` now gates it (PLAN Status 2026-10-06).
- *(added 2026-10-03, MANAFORGE)* **A log entry's field names must not collide with its envelope.** The pump op logged toughness as `t`, overwriting the entry's type; the log-line lookup threw inside render and the screen froze behind "The opponent is thinking". Fix: rename to `tou`; `MF.log` now refuses fields named `t` or `turn`, and a render error opens the crash report with the replayable bug report instead of freezing (`3cf9883`, replayed from the owner's 102-action report, seed 62990426).
- *(added 2026-10-03, MANAFORGE)* **Style lints should refuse the words you don't want.** After the owner's Grim Dark brief the art-prompt lint also rejects soft, playful vocabulary (`dce2a83`), and the style constant leads every prompt (a first sample with the style last came out half-drawn).
