# Gotchas that bit more than one project

*(2026-11-03)* Moved out of `README.md` and grouped by area; the cross-project items from the old `lessons-since-2026-10-17.md` (its sections 1 and 8) are merged in, and duplicates are collapsed. New lessons go at the end of their section, marked `(added <date>, <project>)`.

## Engine, rules and AI
- `legalActions` empty froze the bot (Mallet twice, WarMech once). Zero-cost reactions loop forever (one per window plus a stall cap).
- The UI must never do rules maths; read roll targets from state, not the last event.
- *(added 2026-10-29, Legion Forge)* **Hand-built test context hides integration bugs.** 29 rules errors survived a green suite because keyword tests passed window info that the real engine never supplied. For any hook/window system, keep at least one test per hook that drives real `step()` calls; an independent read-only reviewer with the rulebook found them in one pass.
- *(added 2026-10-29, Legion Forge)* **AI built in parallel with engine fixes needs a reconcile stage** (new decision kinds make it fall back). An exhaustive policy table keyed by decision kind (compile error on a new kind) plus a bench that counts fallbacks turns this into a five-minute diagnosis.
- *(added 2026-10-29, Legion Forge)* **Wall-clock budgets make tests flaky under parallel-agent load.** Inject a clock into the AI and freeze it in tests that compare decisions; give slow simulation tests realistic timeouts until the speed budget is met.
- *(added 2026-11-02, MANAFORGE)* **An engine-only fuzzer can't see the crashes players hit.** On 2026-11-01, 549 random engine games (311k actions) ran clean, while drawing 24k decision states in the real page found three crashes in the first round: a prompt naming an object that only existed in a discarded partial run, a log type with no line, and a stack item whose source is not a card. Sweep the interface too: render every decision from the acting seat, hover, open menus, and flag `undefined`/`NaN`/`null` in the words (MANAFORGE `tools/page-sweep.mjs`, `tools/text-sweep.mjs`, on its unmerged branch `claude/izzet-prowess-orzhov-demons-a07rsk` as of 2026-11-03). The same day, the page gate's "every log type has a line, every question has a prompt" check searched the whole text file for a key, so a prompt named like a log type stood in for its missing line. Check each table on its own.
- *(added 2026-11-03, shadowforge)* **An auditor that reads compiled ability functions gives false FAILs when helper sugar wraps them in closures** (318 false FAILs on 2026-10-29); audit the authored spec, not the compiled function.
- *(added 2026-11-05, wasteland-behemoths)* **Run a seat-balance sim with the first AI, and test each fix separately.** 200 AI-vs-AI games per seat count showed the first player winning 63.5% of 2-player games. Extra starting energy for later seats barely moved it (61.5%). A one-hex opening-move penalty fixed it (54%). Record the per-step table in the spec ([wasteland-behemoths.md](wasteland-behemoths.md)).

## Client and presentation
- *(added 2026-11-06, virtually-off)* **Additive effect materials need `fog: false`**, or they turn into solid walls of fog colour at a distance. **Polled input misses taps shorter than a frame**: keep a per-frame taps set alongside the held-keys set.
- *(added 2026-11-04, assembly-forge)* **A `<Suspense fallback={standIn}>` around a GLB shows the stand-in every time a model is first used**, for example a machine deploying for the first time in a match. Preload at startup, make the loading fallback `null`, keep the stand-in for a failed load only ([rules.md](rules.md) rule 26).
- *(added 2026-11-04, assembly-forge)* **A left-drag pan and a middle-drag rotate is the wrong mouse map**: the owner wants middle pans, right rotates, left picks, with the left pan kept only for two-button mice ([rules.md](rules.md) rule 27).
- *(added 2026-11-04, assembly-forge)* **Phones select text on a long press unless the stylesheet forbids it**, and the iOS callout and tap highlight come with it; the owner called it "super annoying". The CSS block and the gate are in [rules.md](rules.md) rule 24.
- *(added 2026-11-04, assembly-forge)* **A clickable figure, or an invisible hit capsule around one, steals taps meant for the tiles behind it**, and picking becomes hard exactly where the board is busiest. Put the pointer handlers on the tiles only and resolve every tap by hex ([rules.md](rules.md) rule 25).
- Bot acting ahead of animations; results drawn behind the prompt that asks about them.
- *(added 2026-11-01, three-kingdoms-tactics)* **Cinematics freeze the game at their start when each one creates its own renderer.** A conditionally mounted R3F `<Canvas>` makes a new WebGL context and recompiles every shader per cut-in: 3-5 s stalls under SwiftShader, and contexts climbed 1 to 9 in one battle. Keep one canvas for the session, warm up behind the briefing, compile against each scene's own lights, and gate on "no new programs or contexts after warm-up". Full recipe: [recipe-scene-start-hitch.md](recipe-scene-start-hitch.md). The owner said it happened in other games too, but no earlier KB entry records them.
- *(added 2026-11-03, shadowforge)* **Turn rule 21 into a failing check.** Shadowforge's `tools/check-look.mjs` greps the stylesheet for the template's fonts, palette colours, ornament words and corner radii (145 hits on the old re-coloured skin, 0 after the re-skin, 2026-10-30). See [shadowforge.md](shadowforge.md).
- *(added 2026-11-03, shadowforge)* A pop-up inspector (Hide/Show, long-press peek) must sit above every modal, or it is invisible on phones: shadowforge's sat under panels at z 58 and 80 until one shared helper (`U.peekable`, z 110) drew all of them (2026-10-29/30).
- *(added 2026-11-03, mallet-42k)* **E2E click helpers that hard-code a camera go stale when the camera rig changes**, so every deployment click missed; read the live camera (`window.__malletCamera.get()`). A missing favicon (404) failed every spec's "no console errors" check (mallet-42k `cd03230`, 2026-10-23).
- *(added 2026-11-03, MANAFORGE)* **Escape every attribute the HTML inserts, including the apostrophe**: a button labelled "Oracle's Gift" did nothing until `tools/check-pages.mjs` gated it (PLAN Status 2026-10-06). A log entry whose fields reuse the envelope's names (`t`, `turn`) froze the screen; the log now refuses them and a render error opens the crash report (`3cf9883`, 2026-10-03).
- *(added 2026-11-05, wasteland-behemoths)* **A control that stays enabled while an action animates swallows clicks silently.** End Turn looked live during a move animation, but the busy guard dropped the click. Re-render (disable) the controls when an action starts. The e2e only caught it once it waited for the next round instead of the first enabled button.
- *(added 2026-11-05, wasteland-behemoths)* **Rule 25 on a 2D SVG board:** `pointer-events: none` on the token and effects layers, with handlers on the tile groups only. Gate it with `document.elementFromPoint` at a token's centre returning its tile. **Rule 8 sweeps must include SVG `<title>` children**, which browsers also show as native tooltips.

## Figures, art and the GPU
- *(added 2026-11-13, stellar-derelict M5)* **Check the gallery's facing arrow against the loader before trusting a "face the arrow" gate.** The cloud-written gallery said "+Z" while the loader turned every model to -Z (the board's facing N), so a correct figure showed its back in "Front view". Judge facing one model at a time (`?gallery=<slug>` close-up) and write the arrow from the board's facing table.
- *(added 2026-11-13, stellar-derelict M5)* **A textured Hunyuan mesh cannot be simplified afterwards.** Paint exports a triangle soup (30k vertices for 10k faces, every edge a UV seam), so meshopt's simplifier returns it unchanged. Meet prop budgets with `stage_shape.py --faces N` before painting; the optimiser only warns.
- *(added 2026-11-13, stellar-derelict M5)* **FLUX.2 klein image-edit copies the reference's props** (handcuffs, a hose, a skull buckle from the style photo kept appearing), and a long shared prompt body pushes the per-figure weapon line out of the picture (no maul in 4 of 4). Put the weapon line first in the per-figure text and name both hands.
- *(added 2026-11-03)* **The figure style is [rules.md](rules.md) rules 7 and 23.** Changing the style doc does not fix figures that were already generated: record which figures predate the style and regenerate them (Mallet Swordtip `ef34f22`, 2026-10-31).
- `models:optimize` writes meshopt; `GLTFLoader` needs `setMeshoptDecoder` or every GLB silently falls back to the procedural figure.
- Quadrupeds/side-view concepts face the wrong axis (per-unit `yaw` in the manifest); check `?gallery` close-ups, the overview camera hides problems.
- Hunyuan style reference turns everything blue (`--style 0.2 --avoid`); floor-length capes need `--nocut`; Hunyuan paint flattens to pale tan (re-grade); image-to-3D cannot do flat terrain; terrain above about 6k tris costs frame time.
- *(added 2026-10-26)* **Hunyuan 2.1 shape needs about 40 GB of Windows commit charge** (GPU allocations count): free memory first and keep the pagefile large. A failed shape stage is masked by a stale `outputs/<slug>/shape.glb` being re-painted, so clear them first and require `shape done` per slug in the log. Check free space on both drives of the second PC before a batch (its C: drive was nearly full; TEMP on E:). Launch long remote jobs detached with `schtasks`, not over an attached ssh (10-minute tool cap). Stop the local studio services when a session is done with them ([rules.md](rules.md) rule 17).
- Gemini: drifts to 6-7 heads unless the head size is stated in numbers and checked in the image; new free-text follow-ups drift, so edit one clean base image per faction; about 30 images per evening; "Download full size" is unreliable (fetch with `?alr=yes`, or bundle the images with in-page JS into one JSON download); never paste from the clipboard (private text leaked once); 1 in 17 replies is text only.
- *(added 2026-10-26)* **Overnight Gemini batches stall after about an hour behind the Windows screen lock** (keep-awake does not stop it); Claude in Chrome may default to the Mac browser (`list_connected_browsers`, then `select_browser` the Windows one). Details: [not-enough-minerals.md](not-enough-minerals.md) section 11.
- *(added 2026-11-03, MANAFORGE)* **Hosted SDXL can stand in for a missing GPU** when prompts, seeds, size and negative prompt are identical: the Hugging Face router needs provider `fal-ai` (`hf-inference` returned HTTP 410 for SDXL) and bills the owner per image (PLAN D23, 2026-10-31; 238 images, 0 failures).
- Flux: a proper noun invites lettering; vague nouns get filled by the model's prior; "magazine cover" draws a title banner.
- *(added 2026-10-26, Murder Squad)* **Per-item art gates need a concrete reference** (side-by-side with an on-style figure, measured head ratio): a vague "check each image" let 32 off-model concepts through ([rules.md](rules.md) rule 13).
- *(added 2026-10-24, lorecannae)* **GPU reservation lock** for two sessions sharing one GPU: a file `C:\Claude Code Projects\.gpu-lock`. Protocol: reserve while the other run is busy, start after 2 minutes of real idle, render for at most 10 minutes, free VRAM and RAM, delete the lock, leave the other session a full run, and give up a reservation that cannot start within 25 minutes. "Wait for 2 min of idle" alone never fired because the other runs were back to back. The lock file did not exist on 2026-10-26.

## Audio
- *(added 2026-11-13, stellar-derelict M6)* **Generated audio needs levelling before anyone listens.** Stable Audio Open takes ranged from -11 to -56 LUFS for one prompt family (2 of 54 files effectively silent); ACE-Step tracks -13 to -28 LUFS with peaks over 0 dBFS. Level by kind in the measure pass (effects -18 LUFS, beds -24, music and voice -16), level gunshot-class ids by peak so the crest gate still means something, flag files under -42 LUFS as failed takes and re-roll with a seed offset instead of lifting them 30 dB.
- *(added 2026-11-13, stellar-derelict M6)* **Two ffmpeg traps in a measuring tool:** `-ac 1`/`-ac 2` rematrix with -3 dB coefficients (a downmixed stereo file reads 2 dB hot, an upmixed mono file 3 dB quiet): decode at the file's own channel count and mix in code. `alimiter` auto-levels to its ceiling unless `level=false`. On Windows a dev server that just streamed a file holds it: retry the in-place rename.
- One sound per weapon until the flavour map existed; AI gunshots come back with crest factor 2 (real 8-20), so measure and layer; ElevenLabs charged for 502s. Describe the mechanism, state exclusions.
- *(added 2026-10-26, Mallet M12)* **iOS Safari resumes an AudioContext only from `touchend`/`pointerup`/`click`:** keep the unlock listeners for the session and retry. Details: [mallet-42k.md](mallet-42k.md).
- *(added 2026-10-26)* The Audio Studio existed only on an unmerged worktree branch of the `3D Model Generation` repo (`claude/ai-audio-generation-packages-2714d8`, worktree under `.claude/worktrees/`) as of 2026-10-26; a worktree cleanup would delete the only checked-out copy. Check `curl http://localhost:7890/api/status` first and do not modify that repo from a game project. No later source says whether it was merged.

## Windows and local tooling
- *(added 2026-11-06, virtually-off)* **A hidden Claude Browser pane runs `requestAnimationFrame` at about 1 fps.** Drive real-time games through a deterministic `advance(seconds)` hook rather than wall-clock waits and held keys.
- PowerShell 5.1 writes a UTF-8 BOM (Python `json.load` fails); Git Bash `/c/...` paths break Windows Python; Git Bash eats backslashes in `sed -i`; `/tmp` is invisible to node; the built-in browser pane cannot drag three.js models (use Playwright `page.mouse` with >= 10 steps) and can lose WebGL (use `npx playwright screenshot`).
- *(added 2026-10-26)* **Stripped-backslash folders:** Mallet-42k and Fell-in both ended with directories named after a Windows path with the backslashes removed (Fell-in's was `C:iews`), apparently from a path written through shell escaping. Write Windows paths with the Write tool or forward slashes, and check `git status` for stray top-level folders.
- Playwright port reuse serves a stale sibling build; give each worktree its own port. CI runners are about 2x slower (30 s vitest timeout, raised AI timing ceilings).
- *(added 2026-11-03, Mallet Swordtip)* **CI tests that read untracked assets from disk fail the deploy.** Generated GLBs and mp3s are not in the repo, so a test that checks them breaks the Pages workflow; make it warn under `CI` and keep a playthrough with every asset returning 404 (Mallet Swordtip HANDOFF F12, 2026-10-30).
- *(added 2026-10-26)* **Verify machine claims before relying on them.** MythosForge and MANAFORGE `CLAUDE.md` said `gh` was not installed; `gh` 2.102.0 was on PATH on 2026-10-26, and it was signed in as `dragoonant` on 2026-11-03.

## Git, agents and parallel work
- Concurrent `npm install` corrupts `node_modules`; Sonnet agents backgrounding long commands stall; one stage at a time; commit after each stage; after a dead run, `git status`, gates, commit by hand.
- *(added 2026-10-26)* **The pre-commit privacy hook does not protect git worktrees** (`.git` is a file there, so the pattern file is not found and the check passes silently): grep the staged diff for the name and home path by hand, or point the hook at `git rev-parse --git-common-dir`.
- *(added 2026-10-26)* Parallel agents on Windows write CRLF/LF mixes (whole-file diffs): `.gitattributes` `* text=auto eol=lf`, `*.bat text eol=crlf`, renormalise once; `git diff --ignore-cr-at-eol --stat` shows the real change.
- *(added 2026-10-26)* Parallel subagents leave orphaned wait-loop shells: one wait per tool call, never chain polling loops across agents.
- *(added 2026-10-29, Legion Forge)* **Background agents' final replies can be lost** (two container restarts on 2026-10-29 kept every file the agents wrote but dropped their hand-back summaries). Have each agent write its summary into a file it owns and read that, not the transcript.
- *(added 2026-10-29, Legion Forge)* **`git mv` by a running agent stages into the shared index**, so the coordinator's next `git add <paths> && git commit` also commits the agent's half-finished renames (Legion Forge's M1 commit swept in M2a's engine moves and went red; caught by gating the commit in a clean worktree before the push). While agents run, commit with `git commit -m ... -- <paths>` (only those paths) and gate the commit in `git worktree add <tmp> HEAD` with `node_modules` symlinked, never the working tree. Same day, a plain `git add -A` for a docs change swept 20 of another agent's half-written data files into a pushed commit. `node_modules/` (trailing slash) does not ignore a `node_modules` symlink in a worktree.

## Sources and data
- *(added 2026-10-29, Legion Forge)* **Publisher card PDFs are often image-only.** Check for a text layer before planning data entry; community list-builder bundles (e.g. a live JS bundle with embedded card JSON) can be the only machine-readable source, and they can disagree with the printed card, so primary wins and every playable faction gets an eye check.
- *(added 2026-10-29, Xross Forge)* **Look for the publisher's own API before any data entry**: grep the official site's JS chunks for API hosts (`grep -ohE 'api\.[a-z.-]+/v[0-9]/[a-z/_${}]*' chunks/*.js`). Xross Stars exposed cards (with printed text and both leader sides), FAQ and restrictions as unauthenticated JSON. Give the rules agent the official FAQ in its brief: on Xross Forge the FAQ settled 4 of 7 open rulings and reversed one default.
- *(added 2026-11-03, shadowforge)* **Check that a source site covers the right edition of the game.** The tier lists on the site the owner named were for the digital Shadowverse: Worlds Beyond, not the tabletop Evolve (shadowforge PLAN D5, 2026-10-29).
- *(added 2026-11-03, bossforge)* **Wiki-sourced card generators can take a piped link's target instead of its display text**: four Heroes came out wrong and were found by eye (bossforge `8587b28`, 2026-10-29).
- *(added 2026-11-05, wasteland-behemoths)* **Claude may decline to recreate a specific published game.** Asked for "a digital version of the gammarauders game" (TSR, 1987), the session declined to reproduce its name, creatures, card text, art and rules 1:1, and offered an original game in the same family. The owner chose that. The fallback that worked is the three-kingdoms-tactics model: an original spec with rule ids, where "the spec is the product". Expect this on a kickoff, and decide early rather than mid-build.

## Deploy, Pages and cloud sessions
- **A new repo's first Pages deploy fails at `actions/configure-pages`** until Pages is enabled with Source "GitHub Actions", and the default `GITHUB_TOKEN` cannot enable it (Three Kingdoms Tactics, Great Archival Forge). Ask the owner at kickoff. *(added 2026-11-03, bossforge)* The route that needs no settings change: run the gates, then `git push --force origin HEAD:gh-pages` with `permissions: contents: write` and a committed `.nojekyll` (bossforge `11640e4`, PLAN D14, 2026-10-28). `configure-pages` `enablement: true` was tried first and replaced two minutes later; whether it worked is not recorded. *(added 2026-11-13, stellar-derelict)* **The gh-pages route still needs one setting when the repo was created with Pages on the "GitHub Actions" build type:** four green runs force-pushed `dist/` to `gh-pages` and the site stayed a 404. Check `gh api repos/<o>/<r>/pages` shows `build_type: legacy` and `source.branch: gh-pages`; `gh api -X PUT .../pages --input -` with `{"build_type":"legacy","source":{"branch":"gh-pages","path":"/"}}` fixes it and `POST .../pages/builds` serves within a minute.
- *(added 2026-10-28)* **Cloud sessions (claude.ai/code) are a different machine.** They run in a Linux container with no GPU, no local AI studios (Hunyuan, Flux, Audio Studio), no Claude in Chrome/Gemini and no `gh`; GitHub goes through MCP tools, and public sibling repos clone anonymously through the git proxy (`git clone --depth 1 https://github.com/dragoonant/<repo>`). Engine, data, AI and client stages run fine there; art and audio stages must run from a session on the owner's Windows PC. Files outside a pushed commit are lost when the container is reclaimed, so commit and push after each stage.
- *(added 2026-11-03)* **This KB repo is private** (owner decision 2026-11-03). An anonymous clone, a cloud session without access to it, or a game's CI cannot fetch the `docs/knowledge-base/` submodule. On 2026-11-03 no game workflow checked out submodules (`actions/checkout` defaults to `submodules: false`; Xross Forge sets it explicitly), so CI is unaffected. A cloud session that needs the KB must be given access to `dragoonant/tabletop-kb`; if it can't be, read the KB from the owner's PC session and pass the relevant section in the brief.
- *(added 2026-11-13, stellar-derelict)* **A cloud session can be refused push access to this KB repo** even when it can read it. Keep the entry as a draft file in the game repo (`docs/kb-entry-<game>.md`) and copy it across from the PC session at the next milestone, as stellar-derelict did on 2026-11-13.
- *(added 2026-11-05, wasteland-behemoths)* The cloud session's repository list reported this KB repo as **public** on 2026-11-05, against the "private since 2026-11-03" above. Check its visibility before relying on either.
- *(added 2026-11-05, wasteland-behemoths)* **Cloud containers ship Playwright 1.63.0 with Chromium in `/opt/pw-browsers`.** Pin `@playwright/test` to exactly that version so it finds the browser without `playwright install`. The Bash safety check refuses commands it cannot parse for `rm`, such as Python heredoc edits and long heredoc chains, even when they contain no `rm`. Write the script with the Write tool and run it by path.
- *(added 2026-10-26)* **Public release caveat:** the owner prefers public Pages for playtests with the concern stated once; takedown docs must be rewritten in the commit that changes deployment (MythosForge's NOTICE still said "private" after it went public).

## Docs, secrets and the KB itself
- Secrets: ignore `*.token*`, `Tokens.txt`, `tokens.txt*`, `.env*`; read keys only into env vars; personal paths/name once leaked into a public repo's history.
- HANDOFF.md goes stale fast; rewrite STATUS.md instead of appending; `ls` every path a doc claims.
- *(added 2026-10-26)* **Check which checkout is current before copying a sibling, and trust the log over the docs.** Murder Squad's local `main` (2026-10-18) was 70 commits behind `origin/main` (2026-10-24), and the newest code was only visible via `git worktree list`; check `git log origin/main`, `git branch -a` and `git worktree list`. Its STATUS/HANDOFF (10-23) said batches C and D had no figures; the log showed all 219 bodies landed 10-24. Mallet-42k's `HANDOFF.md` still said "continue Mallet 42k to M5" (dated 2026-09-13) after M10-M12 had landed. Trust `git log` and `ls`, then fix the doc.
- *(rewritten 2026-11-03)* **The KB used to be copied into each repo and drift.** By 2026-10-28 three copies existed with different contents. Since 2026-10-29 this repo is the one canonical copy, linked into game repos as a submodule ([README.md](README.md)); the older per-repo copies (murder-squad, mancermundo) are frozen snapshots. Bump the submodule pointer in a game repo after pushing here, and digest sibling commits newer than an entry's last update before relying on it.
