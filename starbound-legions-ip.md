# Starbound Legions: IP posture and UI skin (the only prior Star Wars port)

Written 2026-10-28 for Legion Forge from the `dragoonant/starbound-legions` repo (`b6642bb`, 2026-10-07): `NOTICE.md`, `THEME.md`, `styles.css`, the `sfx/` listing. Engine and card lessons from this project are already in [card-games.md](card-games.md) and [other-projects.md](other-projects.md) item 11; this file covers only what a Star Wars game needs.

## 1. What it is
Star Wars: Unlimited (FFG) card mechanics under an original theme, plain JS, 36 decks / 641 cards, public Pages at `dragoonant.github.io/starbound-legions`. The owner liked its look: "I like how starbound legions presented because it was appropriate to the Star Wars universe" (said while rejecting the same skin for Lorcana).

## 2. IP posture (the alternative to the Mallet posture)
- **Original setting always loaded** (`THEME.md`): the Veil, a star cluster cut off by a storm. Factions: Hegemony (empire), Freeburn (rebellion), Concord (old republic), Severance (machine secession), New Concord, Ashen Order, Wardens (knights attuned to the Current, the Force analogue), Umbra (dark adepts), Syndicate (crime courts) with Trackers (bounty hunters), Vhalkar (armoured clan warriors), Vatborn (grown soldiers), Automa (machines). Named champions, ships and species each have an original name.
- **Real names in exactly one file**, `data/names-source.js`, generated by `tools/gen-source-names.mjs` from a public community card database. The player can switch it off in play; the original names then show. The game loads it, the test suite never does. Two pieces of game vocabulary (the Force token and the unique insignia) swap together with the names, and every log line, prompt and help text is built from them when it renders.
- **Rules text generated at runtime from effect data** when printed text is off; no published wording is stored anywhere else.
- **Voice lines are original** (archetypal beats, never quoted or paraphrased from films or games), pooled by character and trait.
- **NOTICE.md** says: non-commercial, mechanics only, a testbed with no progression; where the real names are; all art and audio original; trademarks of Lucasfilm Ltd. used only to identify the game; not affiliated with FFG, Lucasfilm or Disney; takedown = withdraw the source-name file in one commit and the game keeps running. Maintenance rule: any behaviour change that affects these claims updates NOTICE in the same commit.
- Why it mattered: Disney had the Pixelborn (Lorcana) simulator shut down in 2024 (see [card-games.md](card-games.md) section 9).
- **Legion Forge did not adopt it** (owner, 2026-10-28: Mallet posture, real names everywhere). If a takedown ever comes, this file is the plan for a rename: one names table and a switch, so it is cheap to keep every displayed name behind a single lookup from day one.

## 3. UI skin the owner called appropriate for Star Wars
From `styles.css`:
- Background `#10141c`, text `#dfe6f0`, panel `#1a2030`, lines `#2a3446`, muted text `#93a3bd`, accent gold `#ffd166`, danger `#e5484d`; buttons `#223049` with border `#3a4a68`, 6 px radius; font `'Segoe UI', system-ui, sans-serif`.
- **Colour roles come from `legalActions` only:** actable `#f5c34d` (pulse), selected `#5b9dff`, target `#ff6bcb`, picked `#45c98b`. Faction identity goes in pips and words, never in borders (a faction-coloured border reads as "playable").
- Zone colours: mine `#58b8ff`, theirs `#ff5a5a`, ground `#d9a441`, space `#9a7ad9`.
- No scrollbars anywhere (fit the layout instead); no top bar (round, turn and initiative go in a banner; setup questions on the title screen; everything else in a log drawer).
- Use it as the starting skin for a Star Wars 3D game: dark blue-grey panels, gold accent, the four role colours. Keep Mallet's HUD layout; re-skin it, don't re-lay it out.
