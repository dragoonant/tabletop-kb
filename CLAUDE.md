# tabletop-kb — agent orientation

The shared knowledge base for the owner's tabletop game ports (credited as **evilgouki**). `README.md` is the index; `rules.md` holds the owner's standing rules, `recipe.md` the proven build recipe and `gotchas.md` the cross-project gotchas; each other file is one project's entry or one game's rules primer.

- Read only the section a task needs; files are long.
- Every statement cites where it came from (a project's files, git log, the owner's words with a date). Nothing invented; where a source is silent, say so.
- New lessons are marked `(added <date>, <project>)`. Rewrite stale facts in place rather than appending contradictions.
- Never write the owner's real name, email or home path here.
- The words in `rules.md` rule 23 appear nowhere else in the KB; describe figure and art styles in measurements and materials.
- A new project entry gets a row in the `README.md` index; cross-project lessons go in `gotchas.md` under the matching section.
- Commit messages: `KB: <what>`, then the attribution lines the session provides.
