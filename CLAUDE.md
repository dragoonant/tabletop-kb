# tabletop-kb — agent orientation

The shared knowledge base for the owner's tabletop game ports (credited as **evilgouki**). `README.md` is the index, the owner's standing rules, the proven build recipe and the cross-project gotchas; each other file is one project's entry or one game's rules primer.

- Read only the section a task needs; files are long.
- Every statement cites where it came from (a project's files, git log, the owner's words with a date). Nothing invented; where a source is silent, say so.
- New lessons are marked `(added <date>, <project>)`. Rewrite stale facts in place rather than appending contradictions.
- Never write the owner's real name, email or home path here.
- Commit messages: `KB: <what>`, then the attribution lines the session provides.
