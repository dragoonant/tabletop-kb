## 1. Overview
- Boss Monster (Brotherwise Games): a dungeon-building card game. Each player is a Boss who builds a dungeon of Rooms, lures Heroes with treasure and kills them for Souls; five Wounds lose. Scope is the Base Set (BMR001-BMR096: 8 Bosses, 75 Rooms, 31 Spells, 25 Heroes, 16 Epic Heroes per README), 2-4 players, you vs 1-3 AI Bosses (PLAN D3, D8; RB p4).
- Rules sources: the 10th Anniversary rulebook (2023) plus the Advanced Rules Guide & FAQ; the rulebook wins on conflict (D4). Both PDFs sit in gitignored `scratch/rules/`. Card data comes from the Boss Monster Fandom wiki, original Base Set printing, so the 10th Anniversary's 4 new Bosses and revised cards are missing (D5, DEVIATIONS X1).
- Regime: a reproduction, "fidelity is the product"; printed text on the face; no `BALANCE.md`; a card that does not behave as printed goes in `data/defects.js` and is removed from the decks (CLAUDE.md regime 1-6).
- Owner decisions 2026-10-28 (do not re-ask; KICKOFF.md answers): real card names and printed text (D2); Base Set first (D3); public GitHub Pages (D6); art in the earlier large-head figure style (about 2-2.5 head-heights) with an original 16-bit pixel look, and "10 different proofs for me to pick one" (D7). The first pass was TypeScript/React/Vite; the owner said to "use the knowledge bases" and it was replaced by the plain-JS skeleton (D1; commit `4206a9c`, then `f8ec07a`). On Pages: "push to pages" (D14).
- Owner decision 2026-10-29 (do not re-litigate): style A "Console JRPG" (clean dark outlines, five-tone cel shading, warm light) from `art/proofs/`; "please don't make all the cards look exactly the same pose wise - make them action oriented, so it doesn't look so plain." (D15). Earlier the owner rejected the procedural placeholders as "2 bit art" (PLAN Status).
- Live at https://dragoonant.github.io/bossforge-/ from the `gh-pages` branch (D14). Rights: Brotherwise publishes no fan-content or digital-tools policy (searched 2026-10-28); a licensed digital Boss Monster existed (2014). `docs/rights.md` states the risk once; `docs/takedown.md` gives the withdrawal commands.

## 4. Lessons for the series
- *(added 2026-10-28, bossforge)* **When the token cannot enable Pages, skip the Pages-artifact route: run the gates, then force-push the tested tree to a `gh-pages` branch.** Git order: `298c8fb` used `configure-pages` + `upload-pages-artifact`; `deeae7a` added `.nojekyll` and `with: enablement: true` on `configure-pages@v5` (the action's own option to try enabling Pages); `11640e4` replaced both. `pages.yml` now runs `test.mjs`, `check-pages.mjs` and `stamp-assets.mjs --check`, then `git push --force origin HEAD:gh-pages` with `permissions: contents: write`. D14 says the artifact route "needs a settings change this session could not make", and the workflow comment says Pages was enabled "by the first push of that branch". `.nojekyll` is committed and present on `gh-pages`. Whether `enablement: true` ever worked alone is not recorded.
- *(added 2026-10-28, bossforge)* **A cloud session cannot reach the owner's local Flux Studio: ship the art step as a command and build a no-GPU fallback.** KICKOFF.md: the audition is `node tools/art-audition.mjs` (`--dry-run` first). The session built the proofs and the final art with its own pixel renderer so the owner could choose without waiting.
- *(added 2026-10-29, bossforge)* **When the owner wants variety, make a gate fail on repeats.** `check-pages` fails a card id with no plate and a plate drawn twice (`8587b28`).
- *(added 2026-10-28, bossforge)* **Make withdrawal a one-file lever and write the commands down.** Real names and printed text load only from generated `data/printed.js`; deleting it makes `BF.names` fall back to our own words (CLAUDE.md regime 4). `docs/takedown.md` holds the unpublish, make-private and delete-branch commands, and the commit that changes deployment rewrites it.
- *(added 2026-10-29, bossforge)* **A wiki card table needs cross-checks and a look at the generated output.** Numbers were checked against the rulebook's deck counts and player-count table (D5); `build-printed` still took a link target instead of the printed name for BMR063, BMR066, BMR073 and BMR086 and clipped their flavour text, fixed in `8587b28`.
- *(added 2026-10-28, bossforge)* **When the rulebook and the FAQ disagree, log a numbered RULING with a status word** (Confirmed, Corrected, Unsourced, Fan-source). R1 (end of game) and R2 (priority) follow the 2023 rulebook over the older FAQ.
