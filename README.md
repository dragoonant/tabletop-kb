# Knowledge base: everything learned across the board-game ports

**This repo (`dragoonant/tabletop-kb`, private since 2026-11-03; *(added 2026-11-05, wasteland-behemoths)* the cloud session's repository list reported it **public** on 2026-11-05, so check its visibility before relying on either) is the one canonical copy of the knowledge base** (owner decision 2026-10-29, Legion Forge D16). Game repos link it as a git submodule at `docs/knowledge-base/` (`git submodule update --init`), so every game reads the same files. Edit here, push, then bump the submodule pointer in the game repo. Each game updates its own entry at the end of every milestone and adds cross-project lessons to [gotchas.md](gotchas.md) in the same push ([rules.md](rules.md) rule 19). Older per-repo copies (murder-squad, mancermundo) are frozen snapshots; do not edit them. Because the repo is private, anonymous clones and cloud sessions without access cannot fetch the submodule ([gotchas.md](gotchas.md), "Deploy, Pages and cloud sessions").

First written 2026-10-17 for the Kill Team project ("wh40k-murder-squad"), extended for Mancermundo (2026-10-26) and Legion Forge (2026-10-28), and kept here since 2026-10-29. Every entry was compiled from its project's own docs, specs, tools and git log, plus the owner's words with dates. Nothing here is invented; where a source is silent, the entry says so.
